# Site Subsystem — Local Rules & Constraints

> Constraints for static web portal assets in HATH0R-ATC.

## Rules

1. **Self-Contained**: HTML/CSS/JS must reside entirely in-repo with relative asset paths.
2. **Security**: Content-Security-Policy compliant; no inline executable scripts or eval.
3. **Responsive**: Portable layout across standard desktop and mobile viewports.
